# Массовые операции: обход дерева каталогов

Для этой задачи оптимально подходит **PowerShell-скрипт** с bat-обёрткой. 
PowerShell имеет встроенный `Get-ChildItem -Recurse` и хорошо работает с аргументами. Вызывать его можно из CMD через простую bat-обёртку.

## `mass-op.ps1` — основной скрипт

## `mass.bat` — обёртка для CMD

```bat
@echo off
powershell.exe -ExecutionPolicy Bypass -File "%~dp0mass-op.ps1" %*
pause
```

## Синтаксис вызова

```cmd
mass-op [-mode <mode>] [-root <path>] [-mask <pattern>] [-names <mode>] <команда>
```
Все ключи, кроме выполняемой команды - опциональны. Порядок ключей — произвольный. Команда — всегда последний аргумент.

### Дефолты

| Параметр | Ключ | Дефолт |
|----------|------|--------|
| Режим обхода | `-mode` | `fr` (файлы в дереве) |
| Корень | `-root` | `.` (текущая папка) |
| Маска | `-mask` | `*.*` (все файлы) |
| Вывод имени | `-names` | `none` |

### Режимы обхода

| Режим | Описание |
|-------|----------|
| `f`  | Файлы только в корневой папке (без подпапок) |
| `fr` | Файлы во всём дереве (рекурсивно) |
| `d`  | Папки только в корневой папке (первый уровень) |
| `dr` | Папки во всём дереве (рекурсивно) |

### Режимы вывода имени (`-NameMode`)

| Значение | Описание |
|----------|----------|
| `none`   | Не выводить имя (по умолчанию) |
| `name`   | Только имя файла/папки |
| `rel`    | Относительный путь от корня |
| `abs`    | Абсолютный путь |

### Плейсхолдеры в команде

| Плейсхолдер | Описание |
|-------------|----------|
| `{}`        | Полный путь к файлу/папке |
| `{n}`       | Только имя (с расширением для файлов) |
| `{nb}`      | Имя без расширения |
| `{ext}`     | Расширение с точкой (например, `.txt`) |
| `{r}`       | Относительный путь от корня |
| `{d}`       | Директория (путь без имени) |

## Примеры использования

```cmd
:: Все дефолты — рекурсивно для всех файлов текущей папки с подпапками
mass-op "awk-f addtxt.awk {} XXX"

:: Только маска задана
mass-op -mask *.txt "awk-f addtxt.awk {} XXX"

:: Все параметры указаны
mass-op -root C:\work -mask *.txt -mode fr -names rel "awk-f addtxt.awk {} XXX"

:: Параметры без кавычек (без пробелов в значениях)
mass-op -root ./ -mask *.txt -mode f -names name "awk-f addtxt.awk {} XXX"

:: Только файлы в текущей папке, с выводом имён
mass-op -mode f -names name "findstr /m искомое {}"

:: Удалить все .tmp файлы рекурсивно
mass-op -mask *.tmp "del /q {}"

:: Переименовать все .bak в .txt
mass-op -mask *.bak "ren {} {nb}.txt"

:: Создать подпапку data во всех папках дерева
mass-op -mode dr "if not exist {}\data mkdir {}\data"

:: Вывести размер каждого txt-файла с относительными путями
mass-op -mask *.txt -names rel "for %I in ({}) do @echo %~zI"

:: Выполнить AWK-скрипт замены в определённой папке
mass-op -root C:\project\src -mask *.cpp -names rel "awk-f replace.awk old new {}"
```

## Особенности и ограничения

1. **Экранирование кавычек в команде.** Если в команде нужны внутренние кавычки, используйте одинарные внутри двойных:
   ```cmd
   mass-op fr "C:\root" "*.txt" "echo 'file: {}'"
   ```

2. **Обратный слеш перед кавычкой.** В cmd последовательность `\"` трактуется как экранированная кавычка. Если нужна обратная косая в конце команды, пишите `\\`:
   ```cmd
   mass-op fr "C:\root" "*.txt" "copy {} backup\\"
   ```

3. **Интерактивные команды** (например, `pause` или `set /p`) внутри команды зависнут на первом файле. Для массовых операций используйте только неинтерактивные команды.

4. **Порядок обхода.** PowerShell обходит элементы в алфавитном порядке внутри каждой папки.

5. **Обработка ошибок.** Если команда возвращает ненулевой код, скрипт продолжает работу со следующим элементом (не прерывается).

6. **Пустые результаты.** Если маска не нашла ни одного файла, скрипт выведет `Обработано элементов: 0`.
