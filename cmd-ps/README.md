# Запуск командных оболочек Windows из текущей папки

## cmd.bat и ярлык cmd
Запускают командную оболочку Windows CMD.exe из текущей папки (текущей рабочей папкой в окне сразу становится папка, из которой был открыт ярлык или запущен bat-файл).

## ps.bat и ярлык ps
Запускают командную оболочку Windows PowerShell.exe из текущей папки (текущей рабочей папкой в окне сразу становится папка, из которой был открыт ярлык или запущен bat-файл).
